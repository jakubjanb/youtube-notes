# Sources

`sources/` is the durable source archive.

For YouTube sources, use:

```text
sources/youtube/metadata/<video-or-note-slug>.yaml
sources/youtube/transcripts/<video-or-note-slug>.md
sources/youtube/raw/
```

For external references such as papers, books, blog posts, datasets, or documentation, use `sources/external/`.

Source files should preserve provenance. Keep the original video URL, channel, video ID, date captured, language, and processing status.
