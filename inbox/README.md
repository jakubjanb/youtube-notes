# Inbox

Use `inbox/` for temporary captures that have not yet become canonical source material.

Recommended flow:

1. Save quick video metadata in `inbox/metadata/`.
2. Save rough transcripts in `inbox/transcripts/`.
3. Put uncertain or incomplete items in `inbox/pending/`.
4. Once the source is worth processing, move clean metadata and transcript files to `sources/youtube/`.

Do not treat the inbox as the permanent archive. Anything valuable should eventually move into `sources/`, `blueprints/`, and `notes/`.
