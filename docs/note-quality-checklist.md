# Note Quality Checklist

Use this checklist before marking a note as `reviewed` or `published`.

## Conceptual Clarity

- [ ] The note states what problem or question it answers.
- [ ] The main idea is explained before or alongside formalism.
- [ ] Definitions are precise.
- [ ] The note distinguishes intuition from proof or derivation.
- [ ] Common misconceptions are named.

## Mathematical And Technical Correctness

- [ ] Notation is introduced before use.
- [ ] Notation is consistent throughout.
- [ ] Derivations show all important steps.
- [ ] Calculations have been checked.
- [ ] Units, dimensions, shapes, or limiting cases are checked when relevant.
- [ ] Assumptions are stated clearly.

## Examples And Visuals

- [ ] At least one useful worked example is included when appropriate.
- [ ] Examples are concrete enough to test understanding.
- [ ] Figures support the explanation rather than merely decorate it.
- [ ] Figure sources are stored or reproducible.
- [ ] Captions explain what the reader should notice.

## LaTeX Quality

- [ ] The note compiles without errors.
- [ ] Cross-references resolve.
- [ ] Boxes are used consistently.
- [ ] Equations are readable.
- [ ] Tables and figures fit the page.
- [ ] The PDF is worth keeping as a final artifact.

## Metadata And Knowledge Base

- [ ] `metadata.yaml` is complete.
- [ ] Transcript and blueprint are preserved.
- [ ] Related notes are linked.
- [ ] Concepts are listed for indexing.
- [ ] Tags are reusable and normalized.
- [ ] Prerequisites are listed.
- [ ] Relevant maps of content are updated.
- [ ] Learning paths are updated if the note changes a sequence.
