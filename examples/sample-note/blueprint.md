# Note Blueprint

## Learning Objectives

- Understand the gradient as a local direction of steepest increase.
- Explain why gradient descent moves in the negative gradient direction.
- Interpret the learning rate as a step-size parameter.

## Proposed Note Structure

1. Start with the hill metaphor.
2. Define a loss function.
3. Show the update rule.
4. Work through a quadratic example.
5. Discuss overshooting and convergence intuition.

## Key Equation

```tex
\theta_{k+1} = \theta_k - \eta \nabla L(\theta_k)
```

## Figure Plan

- Plot a convex bowl and a sequence of descent steps.
- A one-dimensional parabola is enough for the sample.
