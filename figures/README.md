# Figures

Use top-level `figures/` for reusable or cross-note assets.

Use note-local `notes/<domain>/<note-slug>/figures/` for assets that belong to one note.

Recommended subfolders:

- `tikz/` for reusable TikZ source.
- `pgfplots/` for reusable pgfplots source.
- `matplotlib/` for scripts or notebooks that generate figures.
- `exported/` for finished image files.

Keep source files whenever possible so figures can be regenerated.
