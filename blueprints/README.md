# Blueprints

`blueprints/` stores structured note plans generated by `youtube_note_architect`.

Use:

```text
blueprints/<domain>/<note-slug>.md
```

Each blueprint should include:

- learning objectives,
- prerequisites,
- conceptual storyline,
- section plan,
- derivation plan,
- examples,
- proposed figures,
- notation conventions,
- quality checks for the final note.

When a final note is created, copy the blueprint into the note folder as `blueprint.md` so the note remains self-contained.
