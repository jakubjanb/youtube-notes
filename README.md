# YouTube Notes

`youtube_notes` is a personal second brain for turning valuable educational YouTube videos into polished scientific notes.

The project separates raw source material, transcripts, AI-generated blueprints, final LaTeX notes, figures, metadata, and knowledge-base indexes. It is designed for long-term growth: hundreds or thousands of notes can live here without losing their provenance, prerequisites, relationships, or learning paths.

## Core Idea

Most videos are useful in the moment but difficult to revisit. This repository turns a good video into a durable learning artifact:

1. Save video metadata and transcript.
2. Use `youtube_metadata_collector` to create clean source metadata from a YouTube URL when you want automated intake.
3. Use `youtube_note_architect` to convert the transcript into a structured educational blueprint.
4. Use `youtube_note_generator` to convert the blueprint into a polished LaTeX note.
5. Store the final note in the relevant domain folder.
6. Update indexes, concept cards, maps of content, and learning paths.

The result is a searchable, linkable knowledge base for mathematics, physics, statistics, probability, machine learning, computer science, quantitative methods, and related technical subjects.

## Folder Overview

```text
config/          Project vocabularies and LaTeX settings.
inbox/           Temporary staging area for new videos, transcripts, and pending work.
sources/         Long-term source archive for transcripts, metadata, raw files, and external sources.
blueprints/      Structured note plans generated by youtube_note_architect.
notes/           Final note folders grouped by domain.
latex/           Shared LaTeX templates, preamble, macros, environments, and build scratch space.
figures/         Reusable figure source files and exported assets.
knowledge-base/  Indexes, concept maps, maps of content, and learning paths.
templates/       Reusable Markdown, YAML, and LaTeX-adjacent templates.
scripts/         Lightweight automation for note creation, validation, builds, and indexes.
examples/        Small example note showing the expected structure.
skills/          Documentation pointers for the related ChatGPT Skills.
docs/            Project workflow, naming rules, schemas, LaTeX style, and quality standards.
```

## Quickstart

Create a new note folder:

```bash
make new-note TITLE="Gradient Descent Intuition" DOMAIN=machine-learning
```

Create source metadata from a YouTube URL:

```bash
make metadata URL="https://www.youtube.com/watch?v=yNpP11ffwVM" DOMAIN=mathematics SUBDOMAIN=complex-analysis
```

Add source metadata and transcript, then run the two Skills:

```text
youtube URL -> youtube_metadata_collector -> metadata
transcript + metadata -> youtube_note_architect -> blueprint
blueprint -> youtube_note_generator -> LaTeX note
```

Compile a note:

```bash
make build TEX=notes/machine-learning/gradient-descent-intuition/note.tex
```

Validate metadata:

```bash
make validate
```

Update generated indexes:

```bash
make update-index
```

## Example Note Lifecycle

1. Put quick captures in `inbox/`.
2. Move canonical transcript and metadata to `sources/youtube/`.
3. Store the architect output in `blueprints/<domain>/<note-slug>.md`.
4. Create or update `notes/<domain>/<note-slug>/`.
5. Keep local copies of `metadata.yaml`, `transcript.md`, `blueprint.md`, `note.md`, and `note.tex` in the final note folder.
6. Save generated figures under the note folder's `figures/` directory.
7. Compile `note.pdf` and keep it next to `note.tex`.
8. Update `knowledge-base/` indexes and maps of content.
